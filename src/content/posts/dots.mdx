my dotfiles: [rvdeguzman/dotfiles](https://github.com/rvdeguzman/dotfiles)

## terminal
### [ghostty](https://ghostty.org)
fast terminal with a cursor shader, `ctrl+h/j/k/l` to move between splits.

## multiplexers
### [tmux](https://github.com/tmux/tmux)
`C-a` prefix, popup session on backtick, `C-h/j/k/l` into vim splits.

### [herdr](https://herdr.dev)
multiplexer that shows what each agent is doing, keys mirror my tmux ones.

## editor
### [nvim](https://github.com/rvdeguzman/nvim)
stripped down lazyvim with harpoon, flash, and oil.

### [emacs](https://github.com/rvdeguzman/doom)
doom on emacs 31, for org and typst.

## harness
### [pi](https://github.com/earendil-works/pi)
minimal coding agent i extend with my own extensions.

## network
### [tailscale](https://tailscale.com)
private network between my devices. very useful when doing work on the go.

## desktop
### [aerospace](https://github.com/nikitabobko/AeroSpace)
i3-like tiling wm, `alt+h/j/k/l` to focus and `alt+enter` for a terminal.

## cli
### [zoxide](https://github.com/ajeetdsouza/zoxide)
`z foo` jumps to a frequent directory.

### [fzf](https://github.com/junegunn/fzf)
fuzzy finder for files and history.

### [ripgrep](https://github.com/BurntSushi/ripgrep)
`rg` for fast code search.

### [bat](https://github.com/sharkdp/bat)
`cat` with syntax highlighting.

### [btop](https://github.com/aristocratos/btop)
resource monitor.

## git
### [lazygit](https://github.com/jesseduffield/lazygit)
git tui, `lazygit` and go.

### [jj](https://github.com/jj-vcs/jj)
still testing it, but it seems really nice for agents working in parallel.

### [hunk](https://hunk.dev)
diff viewer for reviewing changes.

### [gh](https://cli.github.com)
github cli for prs and issues.

## writing
### [typst](https://typst.app)
markup for docs, live preview in doom.

### [org mode](https://orgmode.org)
notes and tasks in emacs, with latex previews.
