# inspo research — homepage prototypes (2026-08-10)

Two scouts failed on generic results; distilled from direct web searches instead.

## techno-minimal moves (for Readme / Changelog / Terminal)
- **Status-bar footer** (vim/tmux style): last-updated, tech stack, current time — metadata as chrome. (lukesmith.xyz-adjacent editor layouts)
- **Keyboard-shortcut hint chip**: small `[?]` reveals key map; production header already has j/k-style tab keys — surface them.
- **Copy-to-clipboard on contact info** — one-click email copy is the single most-used interaction on dev sites.
- **Fake prompt with session history** (already our Terminal variant): `$ cat about.md` → output stream. Validated pattern.
- **Low-contrast theme discipline**: no pure black/white pairs; our tokens already comply.
- Galleries: brutalistwebsites.com (filter minimal/coding).

## digital-garden moves (for Garden)
- **Note maturity states** are the canonical garden signal: seed → seedling → budding → evergreen (Maggie Appleton's visual system is the gold standard). Our Garden uses these as text labels — correct approach for mono aesthetic.
- **Now page ethos** (nownownow.com): now ≠ about; keep the "last watered" freshness stamp.
- Reference gardens: maggieappleton.com, tomcritchlow.com, joelhooks.com, alexisrondeau.com.
- Monospace garden = accepted subgenre (plain-text/Obsidian philosophy) — techno-compatible, not hipster.
